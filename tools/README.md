# tools/ — Einmal-Werkzeuge

Hier liegen Skripte, die **einmal** gebraucht wurden und aus
Nachvollziehbarkeitsgründen im Repository bleiben. Sie gehören nicht zum
Betrieb der Anwendung und werden nicht gewartet.

Betriebs-Skripte (Backup, Restore, Paketbau) liegen in `scripts/`.

| Datei | Wofür | Stand |
|---|---|---|
| `refactor-umlaute-und-kategorien.mjs` | Einmal-Umstellung von ASCII-Umschreibungen auf echte Umlaute und von den alten Mangelkategorien (OM/LM/EM/HM/GM) auf die HU-Richtlinie (OM/GM/EM/GfM) | erledigt, nicht erneut ausführen |
